# 🏡 BhagwatiProperty — Real Estate Web Application

BhagwatiProperty is a modern, responsive real estate platform that allows users to browse, buy, rent, and enquire about properties across different cities. The project combines an attractive frontend UI with backend functionality including authentication and database integration.

---

## 🚀 Features

✨ User Features:
- Browse properties (Buy / Rent)
- Filter properties by location & budget
- Search properties easily
- View property details
- Enquire about properties
- Chatbot support
- WhatsApp direct enquiry

🔐 Authentication:
- User Registration
- User Login
- Password encryption using bcrypt
- JWT-based authentication

📩 Enquiry System:
- Contact form submission
- Data stored in MongoDB

🎨 UI/UX:
- Fully responsive design
- Modern animations and transitions
- Interactive property cards
- Floating chatbot & WhatsApp button

---
